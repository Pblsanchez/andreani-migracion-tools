## Reglas
- Este repo es **público**: las pruebas usan **datos sintéticos**. Nunca subir exports de Integra ni datos de clientes a una prueba.
- Las herramientas permiten cargar el archivo real **en el navegador**.
- Cuando una prueba se aprueba, pasa a su carpeta definitiva y se agrega a `HERRAMIENTAS` en `index.html`.
- Las pruebas no aparecen en la portada.
